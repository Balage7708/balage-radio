# Balage Rádió

Saját webrádió-lejátszó Windowsra és Androidra (Flutter + mpv).

- Kedvencek, keresés kb. 50 000 adó között (Radio Browser), saját stream-cím
- „Most szól” kijelzés, dalelőzmények, Spotify / YouTube keresés
- Két soros LED-es kivezérlésjelző, hangszínszabályzó, hangerő-kiegyenlítés
- Felvétel (egészben vagy dalonként), ébresztő felhangosodással, Windows mini lejátszó

A GitHub Actions minden `main` ágra küldött változás után lefordítja az Android APK-t és a Windows-telepítőt,
és kiadásként (Releases) közzéteszi.
